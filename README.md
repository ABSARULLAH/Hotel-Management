# HOTEL MANAGEMENT SYSTEM
## MySQL Database Project

### 1. Project Overview
The Hotel Management System is a database project developed using MySQL. It manages hotel customers, room details, bookings and payments.

### 2. Objectives
- Store customer information.
- Maintain hotel room details.
- Manage room bookings.
- Track customer payments.
- Retrieve useful information using SQL queries.

### 3. Technologies Used
- Database: MySQL
- Development Environment: Visual Studio Code
- Database Tool: MySQL Workbench / MySQL Server
- Version Control: Git and GitHub

### 4. Database Tables

The project contains four tables:

1. Customers
2. Rooms
3. Bookings
4. Payments

### 5. SQL Concepts Used
- CREATE DATABASE
- CREATE TABLE
- INSERT
- SELECT
- UPDATE
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- JOIN
- Aggregate Functions
- Subqueries
- CASE Statements

### 6. Project Features
- Customer information management
- Room information management
- Booking records
- Payment tracking
- Payment status checking
- Booking and payment reports

### 7. How to Execute

1. Install MySQL Server.
2. Open the project in VS Code.
3. Connect to your MySQL database.
4. Open hotel_management.sql.
5. Execute the SQL statements.
